# CLI App

This project is 2 apps in one. a simple rock paper scissors game where users can play rounds against the computer and see your statistics. Games won, lost, tied, win percentage and total games. As well as a shopping list manager where users can add, view, and remove items from a list. Which shows the quantity and price per item as well as the total amount of items and the total price of the entire list.


## Key Features & Usage Example
After running the application, the user is presented with a menu of options

For Rock Paper Scissors they can:
1. Play a game.
2. View their stats.
3. Exit the application.

For Shopping List Manager they can:
1. Add a new item to their list.
2. View their list of items.
3. Remove items from their list.
4. Exit the application.


## Setup

Follow these steps to get started:

```sh
# Clone the repo
git clone [repo_url]
cd [repo_name]

# Install dependencies
npm install

# Run the respective index.js files
node Rock-Paper-Scissors/index.js

node Shopping-List-Manager/index.js
